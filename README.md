導入の前に（共通の注意）

部品を入れても動かないときは、ほとんどがこの4つです。先に確認しておくと安心です。

クラス名を、HTML・CSS・JSで同じにする hamburger と hamburgar のように、1文字違うだけで動きません。
ファイルの読み込みパスが合っているか <link href="CSS/style.css"> のフォルダ名やファイル名を確認します。
大文字と小文字を区別する パソコンの中では動いても、GitHub Pagesなどの公開先では、JS と js は別物として扱われます。フォルダ名とHTMLの書き方は、必ず同じにします。
<script> は </body> の直前に置く HTMLを先に読み込んでからJSを動かすためです。
